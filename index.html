Student Project API Security Research & BOLA Audit

Empirical vulnerability analysis, automated regression test harness, and object-level policy remediation in a Node.js REST API.
Domain Focus API Security & Access Control
Threat Classification OWASP API1:2023 · CWE-639 / 284
Severity & Metric CVSS 7.5 (High) · 12 Test Checks
Technology Stack Node.js, Express, SQLite, JWT, Supertest
Problem Statement & Research Objective

In multi-tenant web and backend architectures, applications frequently confuse authentication (verifying caller identity via tokens) with authorization (verifying whether that specific caller owns the requested resource). The objective was to construct a reproducible academic project service, model access boundaries, demonstrate cross-user data leakage through client-supplied path keys, and construct an automated regression test harness enforcing strict object-level access policies.

Technical Implementation
  • Backend Architecture: Developed a REST service utilizing Express and SQLite, supporting user authentication, profile reflection, private note management, and role-gated administrative inspection.
  • Flaw Isolation: Isolated the GET /api/notes/:id controller, which validated incoming JSON Web Tokens (JWT) but executed direct database lookups using unverified path parameters without evaluating ownership against req.user.id.
  • Remediation Strategy: Contrasted two mitigation patterns: query-level scoping (WHERE id = ? AND user_id = ?) vs controller-level policy enforcement (note.user_id === req.user.id || req.user.role === 'admin'), establishing uniform 403 Forbidden responses.
My Individual Contribution

Sole researcher and developer: Implemented the Express API, authored the 12-point automated regression test suite, conducted threat modeling against OWASP API Top 10, documented CVSS 7.5 vulnerability findings, and authored the remediation guide.

Computer Network Concepts & Protocol Simulation

Translating network protocol specifications into running Python validation engines, packet simulations, and optimized subnet designs.
Domain Focus Protocol Engineering & Subnetting
RFC Specifications RFC 791, RFC 1071, RFC 1624
Allocation Metric 88.28% Subnet Efficiency (/12–/30)
Toolchain Python, Cisco Packet Tracer, Wireshark
Problem Statement & Engineering Objective

Practical network engineering demands moving beyond theoretical OSI models into deterministic protocol manipulation. The objective was to develop software test suites verifying bit-level IPv4 packet checksums per RFC specifications, evaluate router hop behaviors under TTL manipulation, model control-plane resource starvation (SYN and ICMP flood attacks), and architect an enterprise-grade hierarchical subnet topology using Variable Length Subnet Masking (VLSM).

Technical Implementation
  • RFC 1071 & RFC 1624 Algorithmic Validation: Implemented a Python engine performing 16-bit one's complement addition over IPv4 frame headers. Implemented RFC 1624 incremental checksum update HC' = ~(~HC + ~m + m'), verifying that intermediate routers can update packet checksums after TTL decrement in O(1) time without re-computing the entire 20-byte header.
  • Control Plane Policing (CoPP) & RTBH: Simulated ICMP echo, UDP amplification, and TCP SYN flood behavior. Applied CoPP rate limits (policing ICMP at 50 pps) and Remotely Triggered Black Hole (RTBH) routing via BGP community tagging to null-route attack traffic at edge ingress.
  • Hierarchical VLSM Subnetting: Designed address allocations from /12 down to /30 point-to-point links, isolating management networks, eliminating broadcast domain sprawl, and achieving an 88.28% address utilization efficiency.
My Individual Contribution

Sole author: Developed Python protocol validation test suites, engineered the VLSM mathematical allocation scheme, designed Packet Tracer topologies, and analyzed Wireshark packet captures.

FEATURED PROJECT 03 // SYSTEMS & IDENTITY SECURITY
ACTIVE DIRECTORY HARDENING
CASE STUDY · ENTERPRISE HOMELAB AUDIT

Windows Domain Security & Hardening Lab

Isolated virtual enterprise infrastructure for analyzing centralized identity, Group Policy enforcement, and attack surface reduction.
Domain Focus Enterprise Identity & Hardening
Infrastructure Windows Server 2022, Win 11, VirtualBox
Network Boundary Host-Only Segmented (192.168.56.0/24)
Security Mechanisms AD DS, GPO, LAPS, Kerberos AES-256
Problem Statement & Systems Objective

Enterprise identity architectures predominantly fail not from underlying OS kernel flaws, but from configuration drift, legacy protocol retention (LLMNR, NBT-NS, SMBv1), and flat administrative access tiers that permit lateral movement. The objective was to architect an isolated virtual enterprise domain to study centralized identity boundaries, model credential dumping attack paths, and implement hardened Active Directory baselines.

Technical Implementation & Architecture
  • Isolated Virtual Infrastructure: Deployed a Windows Server 2022 Domain Controller and Windows 11 Enterprise workstations on a segmented VirtualBox Host-Only network (192.168.56.0/24) with zero external internet bridging to prevent telemetry or credential leakage.
  • Tiered Administration Model: Architected Organizational Units (OUs) following the Tiered Administration model: Tier-0 (Domain Controllers, Protected Users), Tier-1 (Member Servers), and Tier-2 (End-user Workstations). This prevents domain-level credentials from ever caching in lower-tier LSASS memory.
  • Group Policy (GPO) Hardening Baselines:
    • LAPS Implementation: Enforced Local Administrator Password Solution across domain endpoints, randomizing local admin passwords and neutralizing pass-the-hash vectors.
    • Poisoning Defense: Disabled LLMNR and NetBIOS over TCP/IP via GPO, neutralizing rogue Responder-style broadcast poisoning.
    • Protocol Deprecation: Disabled SMBv1 and enforced SMB Signing to thwart NTLM relay attacks.
    • Telemetry & Audit: Configured PowerShell ScriptBlock Logging (Event ID 4104) and command-line process auditing (Event ID 4688).
My Individual Contribution

Sole architect and administrator: Virtual machine provisioning, domain controller promotion (AD DS / DNS), directory schema partitioning, Group Policy authoring, and security verification.
